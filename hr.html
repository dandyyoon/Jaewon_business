A

e-HR · 조직 · 발령

직원 마스터 · 조직/직위/직책 · 발령 14종 · 민감정보 통제

발령이 곧 마스터 데이터입니다

  • 발령 등록 → 시행예정·보류 → 반영완료 상태 관리, 시행일 0시에 직원·조직 정보 자동 갱신
  • 신규 입사·전보·승진·직무 변경·겸직 등록/해제·파견·휴직·복직·대기발령·퇴사·조직/직위/직책 신설·폐지 (14종)
  • 미래 시행일 기준 조직도 미리보기 — 조직 개편 시뮬레이션
  • 근로계약·임금 이력(pay base) 관리 → 급여 모듈 연동

민감정보는 권한과 로그로

  • 주민번호·계좌 마스킹, 열람 승인 요청 → 승인 → 접근 로그 기록
  • 역할 4단계(HR · 팀장 · 직원 · 시스템), Supabase RLS로 DB 레벨 통제
  • 재직증명서·발령장·근로계약서 PDF 자동 생성
  • 역할 변경 이력, 조직 변경 이력 보존

B

인사평가 · 360° + KPI

평가 사이클 · 다면평가 · 역량모델 · KPI · 등급 조정 · 면담

사이클 운영

  • 준비→시작→독려→종료→결과 공개 5단계
  • 조직도 기준 평가자(본인·상사·동료·상향) 자동 매핑
  • 미완료자 독려 이메일 템플릿

평가 · 합산

  • 공통·직무 역량모델(필수/선택 항목)
  • KPI 등록·승인·진척 관리, 면담 기록
  • 역량 + KPI 가중 합산, 등급 규칙 설정

공정성 장치

  • 익명 정책(HR만 실명 / 팀장도 실명)
  • 등급 조정(캘리브레이션), 분포 가이드 초과 경고
  • 결과 열람 잠금·해제 요청, 면담 피드백지 PDF

C

급여 자동화

근태 → 급여·4대보험·세액 → 명세서·이체·급여대장

계산은 시스템이, 확인만 사람이

  • 통상임금 기준 연장·야간·휴일수당, 입·퇴사 일할계산, 무급휴가 공제
  • 국민연금·건강보험·장기요양·고용보험·소득세·지방소득세 자동 산출, 건강보험 정산 반영
  • 전월 대비 개인별 공제액 ±15% 변동 경고, 연장 한도 검증
  • 월별 급여 DB 잠금·수정 이력, 임금 변경 이력
